Code-agent CLIs
These launch inside this VM terminal. Missing CLIs install first, then the TUI owns the terminal. Keys, history and sessions stay in the guest. File transfer stays in Workspace: drag files onto the desktop or use File → Upload to Workspace.
Developer tools

Expose publishes one guest TCP port on the internet as https://<subdomain>.<cloudflare.domain> through the Cloudflare tunnel. The process inside the VM must listen on 0.0.0.0 (not localhost). Finish the Cloudflare wizard first. Unexpose from the Services tab. Without Cloudflare this only adds a local proxy route.
